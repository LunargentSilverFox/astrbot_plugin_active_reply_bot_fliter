# AstrBot 关键词静默拦截器

用于主动回复场景的 AstrBot 插件。可过滤用户消息中的指定关键词，并根据自定义系统提示词判断机器人是否应该回复。

## 功能

- 用户消息包含配置的过滤词时，拦截本次消息，不交给机器人处理。
- 将自定义指令追加到系统提示词末尾，指导机器人判断是否需要回复。
- 机器人回复包含静默关键词时，清空回复内容。
- 支持在 AstrBot 插件配置界面中修改过滤词和提示词。

## 安装

在 AstrBot 的插件管理界面中，通过 GitHub 仓库地址安装本插件，安装后启用即可。

## 配置

在 AstrBot 的插件配置界面修改以下选项：

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `client_filter_words` | `[图片]`、`[表情]` | 用户消息包含其中任意词时，拦截本次消息。 |
| `bot_filter_words` | `[沉默]`、`[silent]` | 机器人回复包含其中任意词时，清空回复。 |
| `system_prompt_suffix` | 检查消息是否与机器人有关的提示词 | 追加到系统提示词末尾的文本。可使用 `{bot_filter_words}` 插入当前机器人过滤词。 |

修改配置后保存即可，AstrBot 会重新加载插件配置。

## 注意

机器人回复的静默过滤在发送前检查；本插件不支持流式输出。
